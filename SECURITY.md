# Security Policy

## Reporting a vulnerability

Please do not publish exploit details in a public issue.

If GitHub private vulnerability reporting is enabled for this repository, use the
**Report a vulnerability** option on the Security tab. Otherwise, contact the
repository maintainer through the GitHub profile and request a private channel.

Please include the affected version or commit, the impact, and a minimal reproduction
when safe to share.

Braintop is an evolving research and visualization tool. Do not send secrets, private
model credentials, or sensitive datasets in bug reports.
